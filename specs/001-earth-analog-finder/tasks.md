# Tasks: Earth Analog Finder

**Input**: Design documents from `specs/001-earth-analog-finder/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/, quickstart.md

**Tests**: Included where the constitution requires them (Development Workflow and Quality
Gates: unit tests with hand-computed values for scoring, veto, UNKNOWN handling and weight
renormalisation; schema validation of profiles and results) and where a spec success criterion
can only be checked by a test (site size / no external requests, reproducibility). Write each
test task before or together with the code it checks.

**Organization**: Tasks are grouped by user story (spec.md US1–US5). Each task names the plan
sub-phase it implements (e.g. "plan C2") so the person picking it up can read the goal, inputs
and "done when" there. All paths are relative to the repository root `App/`.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependency on an unfinished task)
- **[Story]**: User story the task belongs to (US1–US5)
- Every task lists its file path(s) and a concrete "Done:" check

## Path Conventions

Single project: `src/analogfinder/`, `tests/`, `config/`, `profiles/`, `schemas/` at the
repository root (see plan.md *Project Structure*).

### Scoring engine (plan D1–D3, research D-012)

- [ ] T027 Create `src/analogfinder/scoring/rules.py` with one function per `scoring_rule`, each returning `CriterionScore(score, deviation, deviation_ratio, state)`: `trapezoid` — `s = 1` inside `[min, max]`; below: `max(0, 1 − (min − x)/τ_low)`; above: `max(0, 1 − (x − max)/τ_high)`; a `null` bound means no penalty on that side; `gaussian` — `s = exp(−(d/τ)²)`, d = distance outside range; `boolean` — 1 match / 0 mismatch; `class_overlap` — weighted Jaccard `Σ min(a_k, b_k) / Σ max(a_k, b_k)` with hierarchy partial credit from `config/mineral_classes.json`; `percentile` — `s = max(0, 1 − |p − p*| / τ_p)`, flagged `relative=True`. Uncertainty widens tolerance: `τ_eff = sqrt(τ² + σ_target² + σ_earth²)` (omit unknown σ). Deviation = d in the criterion unit, `deviation_ratio = d/τ_eff`. ## Phase 3: User Story 1 - Run an analysis for the Mars reference profile (Priority: P1) 🎯 MVP

**Goal**: One command produces a ranked, explained list of Earth candidate areas for the Mars
profile (spec US1; plan B3, C1–C6, E1–E5, I1).
